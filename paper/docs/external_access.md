# External replication access (parallel, not Wave 1)

Independent internally matched case/control data are required before Paper C. An unmatched cohort with the same case/control source split would reproduce the artifact.

## Lane A — All of Us CDRv9 (preferred internally matched design)

- [ ] Does the institution have an All of Us DURA with Controlled Tier?
- [ ] If yes: register, complete training, query UC-by-WGS counts by genetic ancestry before locking a cohort
- [ ] If no: identify signing official and do not wait for this lane to write Paper A/B

Notes: WGS-derived exonic calls are a platform-transport test, not an exact WES replication. UC counts by ancestry are not public.

## Qualification (all lanes)

Cases and controls from one parent cohort; UC distinguishable from Crohn’s and IBDU; non-IBD controls with adequate observation; DNA source / capture / genome centre balanced across labels; joint or reference-confidence genotypes; locked 460-gene (or frozen autoimmune) representation applied without refitting if claiming external model validation.
